The documents folder contains the following files:
- function_overview.md: Descriptive overview of all files in the src folder.
- getting_started_replication.jl: Script to replicate getting_started guide.
- getting_started.md: Getting started guide.
- State_of_Package.xlsx: Excel file to track the state of the package.

During the writing of the thesis and development of the package I ran multiple tests and simulations which are not included here. The files are mostly undocumented and unorganized but especially concerning speed and memory usage and simulation setup there could be some useful information/functions. They can be found in the thesis repository: https://github.com/flo1met/thesis_TTE/tree/main/other_files
